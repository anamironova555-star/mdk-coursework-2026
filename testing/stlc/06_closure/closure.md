# Закрытие

Условия входа/выхода выполнены для локального стенда. Изоляция данных помогла безопасно проверить сбой. Рекомендации: проверять Location редиректа, Content-Type, тела и граничные случаи. Публичный example.com не обязан отвечать 200 на все придуманные пути; результаты такого прогона интерпретируются по его реальному контракту.

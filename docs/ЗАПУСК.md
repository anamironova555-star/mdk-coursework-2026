# Как запустить проект

### 1. Подготовка окружения
Создаем виртуальное окружение и ставим библиотеки:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск практик по веб-разработке (МДК 09.01)
Каждая работа лежит в своей папке в `web/`:
* Практика 1 (создание таблицы в SQLite): `python web/practice_01/init_db.py`
* Практика 2 (меню в консоли): `python web/practice_02/crud_console.py`
* Практика 3 (сервер Flask): `python web/practice_03/app.py`
* Практика 4 (вывод задач из базы на страницу): `python web/practice_04/app.py`
* Практика 5 (форма добавления задач): `python web/practice_05/app.py`

После запуска Flask приложение открывается в браузере: http://127.0.0.1:5000

### 3. Запуск тестов
Все юнит-тесты запускаются командой:
```bash
pytest
```

### 4. Скрипты тестирования (МДК 05.03)
Все работы лежат в папке `testing/`. Заходим в нужную папку и запускаем скрипт, например:
```bash
cd testing/bash_basics
bash run_all.sh
```
